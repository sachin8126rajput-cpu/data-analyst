PROJECT: Google Play Store Analysis

Files:
- play_store_apps_dataset.csv: practice dataset
- analysis.ipynb: Jupyter Notebook
- analysis.py: Python script

How to run:
1. Install Python and Jupyter (or Anaconda).
2. Open this folder in VS Code.
3. Open analysis.ipynb and select Python kernel.
4. Run cells top to bottom.
5. Keep dataset CSV in the same folder as notebook.

Note: dataset is synthetic/sample data for learning and demonstration. If internship evaluator requires an external dataset, use a public Kaggle/UCI dataset and update the notebook accordingly.
